# Nonfreeness for rational two-parabolic groups with numerator 24

Author: Ziheng Wang

Repository: https://github.com/wingsyuyi-satori/nonfree-G24r

Affiliation: University of Chinese Academy of Sciences, Hangzhou Institute for Advanced Study, Hangzhou, China

This folder contains the editable English manuscript and its PDF. It has been prepared for the author's review and distribution; no external submission or publication is performed by these files or build commands.

## Files

- `main.pdf`: complete manuscript, including every finite rule, exceptional exponent list, and exact matrix value
- `main.tex`, `author.tex`, `verification_status.tex`, `references.bib`: editable LaTeX sources
- `data/compact_certificate.json`: the complete 48-rule and 23-word certificate
- `verify_certificate.py`: exact Python standard-library checker and table generator
- `data/verification.json`: its checked finite results
- `data/*_table.tex`: tables regenerated by the checker
- `build.sh`: build instructions in executable form
- `中文概览.txt`: short Chinese overview

## Build

Requirements: Python 3, a TeX installation with pdfLaTeX, BibTeX, latexmk, Latin Modern, amsmath/amsthm, mathtools, geometry, microtype, booktabs, enumitem, needspace, hyperref, and cleveref. These are standard TeX Live packages.

Run:

```sh
bash build.sh
```

Or run the two stages explicitly:

```sh
python3 verify_certificate.py
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The checker uses exact integers and `fractions.Fraction`, with no external Python packages. It exhausts all 40320 residue classes, checks every rule, verifies all 23 lower-triangular matrices and full relation words, and checks every syllable bound. It regenerates the paper's tables from the checked data. Use `python3 verify_certificate.py --check` to verify that the committed report and tables match without rewriting them. Run without Python's `-O` flag so the arithmetic assertions are checked. The infinite construction is proved algebraically in the paper and formally in the accompanying Lean project; finite enumeration is not used as a replacement for that proof.

The build script contains a narrowly scoped fallback for a read-only Debian TeX installation whose generated format/database files are missing. The fallback only writes local TeX support files under the system temporary directory. It does not install software or change system configuration.

## Formal proof

The companion Lean repository supplies the all-integer abstract nonfreeness theorem, the 64-syllable relation theorem, the faithful rational-to-complex embedding, the direct five-power identity, and the two-step theorem for |r| > 17. Its pinned dependencies, theorem statements, axiom audits, exact independent replay status, and commands belong to that repository's verification report. The manuscript's formalization section describes that scope.
